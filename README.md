# ENT-AI Mobile Diagnostic System

## Overview
ENT-AI is an AI-powered mobile diagnostic system for screening ear diseases using otoscopic images. The system combines a portable imaging device, mobile application, and deep learning model to support real-time diagnostic assistance.

## System Pipeline
Otoscope Camera → Image Acquisition → Mobile App → AI Model → Diagnosis Result → PDF Report

## Technologies
- MobileNetV2
- TensorFlow Lite
- Flutter Mobile App
- Otoscopic Image Classification
- On-device AI Inference

## Dataset
The model was trained and evaluated using a balanced otoscopic image dataset containing four classes:
- Normal
- Myringosclerosis
- Chronic Otitis Media
- Earwax

## Features
- Real-time otoscopic image analysis
- Mobile-based diagnosis workflow
- Patient history tracking concept
- Automated clinical report generation
- On-device inference using TensorFlow Lite
